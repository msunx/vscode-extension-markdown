# Folio · 暮色紫

这份文档集中展示 Markdown 的标题、引用、代码、待办和扩展语法。点击右上角的铅笔返回编辑，或按 ⌘⌥V 切换模式。

> 先让最小链路跑通，再逐步补充功能。好的文档，应该让下一位接手的人少猜一步。

## 快速开始

使用 **Node.js 22**，在项目根目录依次执行以下命令，生成 Folio 的 VSIX 安装包。

```bash
npm ci
npm run check
npm run package
```

### 定义应用配置

下面的 TypeScript 片段用于展示代码高亮。它不代表 Folio 的可配置项。

```typescript
export const config = {
  name: 'workspace',
  theme: 'twilight',
  preview: {
    enabled: true,
    maxWidth: 760,
  },
};
```

## 脚注与补充排版

重要的信息可以放到脚注中[^reading]。支持 ==高亮标记==、H~2~O 下标与 x^2^ 上标。

[^reading]: 脚注带返回链接，方便继续阅读原文。

Markdown
: 以纯文本记录内容，再由预览呈现结构。

HTML 提供少量必要的结构补充。

*[HTML]: HyperText Markup Language

<details>
<summary>展开查看快捷键</summary>

使用 <kbd>⌘</kbd> + <kbd>⌥</kbd> + <kbd>V</kbd> 切换编辑和预览。

</details>
